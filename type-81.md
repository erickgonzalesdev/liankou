# Type 81 rifle

The **Type 81 rifle** (81式步枪) is the standard ranged weapon below and on the service band. It is a semi-automatic rifle logged to [Zone Protection](zone-protection.md) for seizures. Taken examples circulate in the [lower stack](lower-stack.md).

| | |
| --- | --- |
| Type | Semi-automatic rifle |
| Origin | Domestic |
| Used by | Zone Protection, lower-stack circulation |

It is the ranged arm of a Protection detail that is not carrying a machine gun. The higher-grade scoped rifle used in the sealed galleries does not leave those floors on paper. The squad that sentenced [Liang Zhi](protagonist.md) carried Type 81s.
