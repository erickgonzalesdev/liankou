# Type 79 light machine gun

The **Type 79 light machine gun** (79式轻机枪) is the small machine gun of the Liankou Special Zone. It is drum-fed, shoulder-controllable in short bursts, and issued to [Zone Protection](zone-protection.md) details for seizures. Taken examples are held by some landing bosses in the [lower stack](lower-stack.md).

| | |
| --- | --- |
| Type | Light machine gun |
| Feed | Drum |
| Origin | Domestic |
| Used by | Zone Protection, some lower-stack bosses |

It is the step up from a pistol or a pump when a landing or a corridor has to be held. It is not the belt-fed gun. That is the [Type 67](type-67.md), which rarely leaves the band.
