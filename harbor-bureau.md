# Liankou Harbor Bureau

The **Liankou Harbor Bureau** (联口港务局) is the state port authority of [Liankou](liankou.md). It operates berths and cranes built by [Liankou Development](huanan-development.md).

| | |
| --- | --- |
| Type | State authority |
| Industry | Port operations |
| Founded | 1978 |
| Headquarters | Wall berths, Liankou |
| Parent | Zone administration |

## Operations

A dock token from the [Regulation Office](regulation-office.md) opens a berth. Demurrage (滞期) accrues to the bureau when a stamp is late. Charter and foreign-plant cargo take the day tide. Small lighters, including [Minfa](minfa.md), take what remains and become illegal past the hour. The bureau does not own the cargo.
