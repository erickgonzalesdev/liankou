# Type 67 general-purpose machine gun

The **Type 67 general-purpose machine gun** (67式通用机枪) is the larger machine gun in Liankou service. It is belt-fed. It is logged to [Zone Protection](zone-protection.md) posts on the service band and to sealed galleries in the upper city. It is not man-portable for long.

| | |
| --- | --- |
| Type | General-purpose machine gun |
| Feed | Belt |
| Origin | Domestic |
| Used by | Zone Protection (band and crown), gallery posts |

A Type 67 below the service band is a taken weapon. Its appearance on a landing is an event. Protection treats a missing 67 as a report. The [Type 79](type-79.md) is the gun that actually circulates.
